# S-52 ENC Viewer — 코드 설명

브라우저에서 S-57 ENC(`.000`) 셀을 읽고, IHO S-52 표현 규칙에 가깝게 2D 캔버스에 그리는 **정적 웹 뷰어**입니다. 서버는 정적 파일 제공과 셀 인덱스 API 역할만 하며, 파싱·표현·렌더링은 모두 클라이언트 JavaScript(ES 모듈)에서 수행합니다. 선택적으로 **육지 위에 위성 타일**(Esri World Imagery)을 ENC 해안과 맞게 오버레이할 수 있습니다.

**이 문서를 웹 페이지로 보려면** 저장소 루트의 `about.html`을 `npm run serve` 등으로 연 주소에서 여세요(예: `http://localhost:8000/about.html`). `file://`로 직접 열면 브라우저 보안 때문에 마크다운을 불러오지 못할 수 있습니다.

---

## 1. 전체 데이터 흐름

```text
[ENC .000 바이너리]
       ↓
  DDF.parse (iso8211.js)  … ISO 8211 레코드 트리
       ↓
  S57.build (s57.js)      … 피처 목록 + 경위도 기하 + 속성
       ↓
  S52.resolve (s52.js)    … Lookup 매칭 → 그리기 연산(AC/LS/SY/TX/…)
       ↓
  Renderer.render (render.js) … Web Mercator 투영 + 캔버스 2D 드로잉
```

- **셀 목록·범위**: `cell-index.json`(빌드 산출물) 또는 `serve.js`의 `/api/index`가 `000/` 폴더의 `.000` 파일들로부터 경계 박스와 컴파일레이션 스케일(CSCL)을 미리 계산합니다(`lib/cell-index.mjs`).
- **좌측 셀 목록**: 인덱스의 모든 `.000`을 폴더 트리로 보여 주고, 검색창은 **이름·경로 문자열**로만 걸러 냅니다. 트리 안 **행 순서는 인덱스·경로 기준으로 고정**이며, DOM 재배치는 하지 않습니다. 현재 지도 뷰와 겹치지 않는 셀 행만 **흐리게** 표시해 화면 안 셀과 구분합니다(`syncCellListInViewportHighlight`, `namesIntersectingViewport` in `js/main.js`). **체크박스**는 레이어 표시 on/off만 바꾸고, **행(파일명·색 점) 클릭**은 해당 셀 범위로 뷰를 맞춥니다.
- **실제 도형 데이터**: 사용자가 체크하거나 뷰포트와 겹치는 셀만 `fetch("000/파일명")`으로 불러옵니다(`js/main.js`).

## 3. 모듈별 상세

### 3.1 `js/iso8211.js` — DDF 파서

- ENC 기본 셀은 **ISO 8211** 포맷입니다. DDR(Data Descriptive Record)로 필드 태그·서브필드 레이블·포맷 문자열을 읽고, 이후 각 DR(Data Record)를 같은 스키마로 디코딩합니다.
- `parseFormatControls`가 `(A(2),I(5),2b24,…)` 형태를 펼쳐 서브필드 단위 타입/폭 목록으로 만듭니다.
- `readSubfield`는 고정폭 ASCII(`A`/`I`/`R`), 이진(`b`), 비트열(`B`) 등을 처리합니다.
- 산출물: `ddf.records[]` — 각 원소는 `{ fields: { 태그: [행객체, …] }, order }` 형태입니다.

### 3.2 `js/catalog.js` — 객체·속성 카탈로그

- S-57 파일 안의 `OBJL`, `ATTL` 등은 **숫자 코드**로 저장됩니다.
- `s57objectclasses.csv`, `s57attributes.csv`를 fetch하여 `objClasses`, `attrCodes` 맵을 만듭니다.
- `parseCSV`는 따옴표·쉼표 이스케이프를 고려한 단순 CSV 파서입니다.

### 3.3 `js/s57.js` — S-57 의미 계층

`S57.build(ddf, catalog)`는 대략 다음 두 패스로 동작합니다.

1. **벡터 패스** (`VRID`): `SG2D`/`SG3D` 좌표를 `DSPM.COMF`, `SOMF`로 나누어 도 단위·수심 값으로 환산하고, `VRPT`로 엣지의 시작/끝 노드를 연결합니다.
2. **피처 패스** (`FRID`): `OBJL`·`PRIM`(점/선/면)·`ATTF`/`NATF` 속성·`FSPT` 공간 포인터를 읽어 `features[]`를 만듭니다.

피처 객체 형태(요약):

- `acronym`: 객체 클래스 약어(카탈로그 기준).
- `prim`: 1=점, 2=선, 3=면.
- `attrs`: `{ SCAMIN, DRVAL1, … }` 등 약어 키.
- `geom`: `{ type: "Point"|"Line"|"Area", coords: … }` (경위도 도 단위).
- `soundings`: `[[lon, lat, depth], …]` (해당 시).

면 기하는 `assembleRings`로 엣지 체인을 이어 닫힌 링 배열로 만듭니다. 반환값에는 전 피처를 덮는 `bounds`와 스케일 계수 `comf`, `somf`가 포함됩니다.

### 3.4 `js/s52.js` — S-52 표현 엔진

- `chartsymbols.xml`(OpenCPN이 배포하는 IHO PL 인코딩)을 로드합니다.
- **색상표**(`color-table`), **Lookup**(객체 약어별 조건+지시문), **심볼 비트맵 위치**(아틀라스 내 `x,y,w,h` 및 피벗)를 메모리에 적재합니다.
- `selectLookup(feat, tablePref)`: 기하 타입이 일치하고, `attrib-code` 조건이 가장 잘 맞는 Lookup을 고릅니다(표 이름 선호는 점수에 반영).
- `resolve` → `instruction` 문자열을 `AC`/`AP`/`LS`/`LC`/`SY`/`TX`/`TE`/`CS` 단위로 쪼개 실행해 **내부 draw op 배열**로 변환합니다.
- `S52.displayCatRank` / `minDisplayRankForObjectClass`: Lookup의 `display-cat`로 객체 클래스를 Base·Standard·Other 구간으로 묶을 때 사용(오브젝트 사이드바). `DEPCNT`는 PL이 Other인 경우가 많아 **Standard 구간**으로 고정합니다.

지원·단순화 요약:

- `AP`(영역 패턴)는 **반투명 단색 채움**으로 근사합니다.
- `LC`(복합선)는 **굵은 단색 선**으로 근사합니다.
- `CS(…)`는 `DEPARE`/`SEABED` 수심색, `DEPCNT`, `SOUNDG`, `LIGHTS`, 위험물 일부, `DATCVR`(ENC 커버리지·스케일 경계 윤곽선), `RESARE`, `RESTRN01`(ACHARE), `QUAPOS`/`SLCONS` 등 **시각적으로 중요한 부분집합**만 처리하고, 나머지는 Lookup에 포함된 리터럴 명령에 의존합니다.

색상표 전환은 `setColorTable(name)`으로 `currentTable`을 바꿉니다. 렌더러는 테이블이 바뀌면 피처별 캐시된 해석 결과를 무효화합니다.

### 3.5 `js/render.js` — 캔버스 렌더러

#### 좌표계

- 화면 투영은 **Web Mercator**와 동일한 스케일 관계를 쓰기 위해, X는 **경도(도)를 라디안으로 변환한 값**, Y는 **위도의 등적위형식 `ln(tan(π/4+φ/2))`** 로 캐시합니다. 피처 단위로 한 번만 `mercX`/`mercY`를 적용하고(`_prep`), 매 프레임은 `Viewport.sx`/`sy`의 선형 변환만 수행합니다.

#### `Viewport`

- `fit(bounds)`: 주어진 경위도 박스가 캔버스에 들어가도록 `scale`, 중심 `cx`, `cy` 설정.
- `scaleDenominator()`: 중심 위도·스케일로부터 대략 **1:N 표시 축척**을 추정(SCAMIN·SCAMAX·셀 컴파일 스케일 비교, 동적 폰트 크기 결정에 사용).

#### `Renderer.render()` 파이프라인

1. 배경: S-52 색 `DEPDW`로 전체 클리어.
2. 다음 프레임-스코프 자료구조를 초기화합니다:
   - 라벨 박스 충돌 인덱스(`_labelBoxes`)
   - 통항·조류 화살표 디클러터 격자(`_flowArrowGrid`, Map)
   - 항행보조시설 dedup 격자(`_pointSymbolGrid`, Map)
   - 동적 폰트 크기(`_labelFontPx`, `_soundingFontPx`) — `denom`의 로그에 비례하여 9 ~ 16 px 사이에서 결정
3. 보이고 로드된 셀의 각 피처에 대해:
   - 옵션에 따라 **SCAMIN**·**SCAMAX**(표시 분모 `denom`과 비교: 축소 시 SCAMIN 초과면 생략, 확대 시 SCAMAX 미만이면 생략), **표시 범주**(`minDisplayCat`), **원근간략화**(`scaleDisplay` + 셀 `cscl`), 뷰 밖 **바운딩 박스 컬링**, 아주 작은 면/선 **서브픽셀 스킵**.
   - OpenCPN `chartsymbols.xml`에서 **DEPCNT**(및 선형 **DEPARE**) 룩업의 `display-cat`이 `Other`로만 정의된 경우가 있어, Standard 뷰에서 수심 등고선이 사라지지 않도록 `depthContourStandardDisplay`로 필터 시에만 **Standard와 동등**으로 취급한다.
   - **셀 격자**가 **켜져 있으면** ENC 메타 **`M_COVR`·`M_CSCL`** 을 데이터 경계로 그림(기본 표시범주 Standard에서도 `Other`로 분류된 이 객체들만 예외 허용). **꺼져 있으면** 해당 객체·UI 셀 격자 모두 생략(검정 윤곽 제거).
   - 색상표가 바뀌지 않았다면 `feat._res`(이미 해석된 ops) 재사용.
   - resolved 엔트리에 셀 CSCL(`cellCscl`)을 같이 기록 — 패스 3의 다중 축척 우선순위 판정에 사용.
4. 화면 안에 들어오는 모든 셀의 (Mercator) 경계 박스와 CSCL을 모은 **`navaidCells` 인덱스**를 만들고, `_bestCsclAt(mx, my)`로 임의 위치에서의 **가장 상세한(가장 작은) CSCL** 을 즉시 조회할 수 있게 합니다.
5. `DISP_ORDER`에 따른 **우선순위 정렬** 후 패스:
   - **패스 1**: 면 `AC`/`AP` 채움(evenodd). 다중 축척에서 개략 셀의 그 외 면(DEPARE 등)은 bbox **중심만** 보고 생략하면 경계 직사각형 아티팩트가 나므로, `_supersededByFinerForExtent`(모서리+중심)로만 생략하고 **CSCL 거친→상세** 순으로 칠한다. `LNDARE`(육지면)는 생략하지 않고 동일 순서로 겹쳐 상세 ENC 육지가 위에 오게 한다.
   - **패스 1.5**(옵션): **위성 타일**을 육지 클립 안에만 그린 뒤, 모은 **바다(DEPARE 등) 면**을 위성 위에 다시 칠해 항만·만이 위성에 덮이지 않게 한다(`showSatellite`, `_drawSatelliteLand`). 자세한 동작은 아래 **§5.3** 참고.
   - **패스 2**: `LS`를 스타일 키(`색|두께|점선`)별로 묶어 `_strokePolys`로 배치 스트로크.
   - **패스 3**: `SY`(아틀라스 블릿, `ORIENT` 등 회전), `SOUNDG`, `TX`.
     - **다중 축척 셀 우선순위 필터**: `declutter` 시, 피처가 속한 셀의 CSCL이 그 위치의 최상세 CSCL × 1.5보다 더 개략이면 `SY`/`SOUNDG`를 건너뜁니다. 결과적으로 OpenCPN처럼 위치마다 가장 상세한 셀의 부이·등화·사운딩만 그려져, 셀 중복 표시가 사라집니다.
     - **항행보조 dedup**: 그래도 남는 미세 어긋남을 잡기 위해, 부이(`BOY*`)·비컨(`BCN*`)·`LIGHTS`(색 기준) 등 navaid 계열은 화면상 24 px 이내에 같은 그룹이 이미 그려졌으면 건너뜁니다.
     - **방향 화살표 dedup**: TSS·항로·추천항적·조류 화살표는 64 px 거리 기반(3×3 이웃 버킷 검사)으로 솎습니다.
     - **장애물 점심볼(광역)**: 표시 분모가 약 1:4.5만 이상(축소 뷰)일 때만 `ISODGR`·`OBSTRN`·`WRECKS`·`UWTROC` 계열 점 심볼을 화면 픽셀 격자로 띄엄 그려 연안 과밀을 완화한다(`_hazardSymbolGrid`).
6. 옵션 시 셀 **커버리지 격자**(`_drawGrid`) — 포커스된 셀만 흰색 외곽선으로 강조, 나머지는 외곽선 없이 배경 채움+라벨만 표시. **ENC `M_COVR`·`M_CSCL`** 경계도 격자와 함께 그린다(격자를 끄면 데이터 경계선도 생략).
7. 옵션 시 **경위도 눈금선**(`_drawGraticule`) — 화면 범위에 맞춰 간격 자동 선택(약 18개 전후 눈금, 1.5°·0.5° 등), 소수 자릿수는 간격에 따라 가변.
8. **좌하단 축척 바**(`#scale-bar`): 표시 분모(약 1:N)와 거리 눈금을 갱신한다.
9. `lastStats`에 그린 수·컬링 수·축척 기록.

#### 성능 관련 구현

- **패닝**: `beginPan`에서 마지막 프레임을 스냅샷 캔버스에 복사하고, 드래그 중에는 `previewPan`으로 **이미지 이동만** 수행해 전체 재계산을 피합니다. 마우스 업 시 전체 `render()`로 복귀합니다.
- **경로 단순화**: `_path`에서 연속 정점이 화면에서 ~1px 이내이면 생략(링의 마지막 점은 유지).
- **라벨·수심**: `declutter` 시 `_place`로 사각형 겹침을 검사해 밀집을 줄입니다. 라벨 박스는 동적 폰트 크기에 비례해 크기가 조정됩니다.
- **동적 폰트**: 라벨·사운딩 폰트 크기는 현재 표시 축척(`denom`)의 로그에 따라 자동 조절. 확대할수록 글자가 커져 가독성을 높이고, 축소할수록 줄여 화면 과밀을 막습니다.

### 3.6 `js/main.js` — 애플리케이션 조립

- 초기화 순서: `S52.load` → `loadCatalog` → 아틀라스 이미지 → `Renderer` 생성 → `cell-index.json`(실패 시 `/api/index`)으로 그리드·셀 맵 구축 → **전역 경계 `fit`** → `draw` → `?cell=`이 없으면 **데스크톱만** 뷰포트와 겹치는 셀을 `loadMany`로 병렬(청크 크기 4) 로드·표시.
- **데스크톱**: 첫 로드는 `namesIntersectingViewport()`에 대해서만 `loadMany`를 호출합니다(전체 ENC 일괄 로드 없음).
- **모바일(768px 이하)**: 초기에는 ENC를 자동으로 받지 않고, **팬·줌(또는 `?cell=`)** 이 있을 때만 `scheduleMobileViewportSync`(약 220ms 디바운스) → `flushMobileViewportSync`에서 `namesIntersectingViewport`에 맞춰 필요한 셀을 로드합니다. 로딩 중에 뷰가 또 바뀌면 같은 플러시 루프에서 한 번 더 돌아 **최신 화면**에 맞춥니다. 동시에 여러 `loadMany`가 겹치지 않도록 Promise 체인으로 직렬화합니다. 하단 오버레이(`#map-loading`)는 로딩 중에만 표시합니다.
- 셀 바이너리 URL: `000/<셀파일명>` (정적 경로).
- **ENC 열기 통합 메뉴**: 툴바의 `ENC 열기 ▾` 한 버튼으로 **파일 다중 선택**과 **폴더 일괄 선택**을 모두 지원합니다(드롭다운 항목으로 분기). 폴더 선택은 `webkitdirectory`가 지원되는 브라우저에서만 활성화됩니다.
- **키보드 단축키**:
  - `↑↓←→` / `WASD`: 화면 패닝.
  - `Equal`/`NumpadAdd` · `Minus`/`NumpadSubtract`: 확대/축소(`KeyboardEvent.code` 기준이라 레이아웃 무관).
  - `1`~`9`: 해당 번호로 저장된 뷰포트(중심·축척) 복원.
  - `Ctrl+1`~`Ctrl+9`: 현재 뷰포트를 해당 번호 슬롯에 저장 (localStorage `encViewerBookmarks`).
  - 텍스트형 `INPUT`·`TEXTAREA`·`SELECT`에 포커스가 있을 때만 무시합니다.
- 파일 입력·드래그앤드롭: 단일 `.000`를 파싱해 임시 셀로 넣거나 기존 셀을 갱신합니다.
- 쿼리 `?cell=파일명`: 해당 셀을 URL에서 불러 표시(`loadFromUrl`).
- 전역 훅: `window.s52app = { state, loadFromUrl, setCellVisible, draw }` — 콘솔·외부 스크립트에서 디버깅·연동 가능.
- **사이드바 탭**: **셀** — 폴더 트리·검색·보이는 영역 표시/숨김/전체보기. **오브젝트** — 로드된 ENC에 등장하는 객체 클래스(약어)별 건수·표시 on/off(`renderer.hiddenClasses`). 클래스 설명은 `s57objectclasses.csv`(영문명)·`s57objectclasses-ko.csv`(약어 한글)로 목록에 병기하고, 필터는 **영문·한글 모두** 검색됩니다. 상단 **표시 중 전체(합산)** 또는 **셀 단위** 범위(`#objscope`), 검색(`#objfilter`), **전체 카탈로그 보기**, **표시범주에 맞춰 목록 축소**(`#objMatchDispcat`: 툴바 표시범주와 같을 때만 실제로 그려질 수 있는 클래스만 남김)를 지원합니다. 목록은 S-52 Lookup의 `display-cat`을 바탕으로 **Display Base / Standard / Other** 구간 헤더로 나뉩니다(`S52.displayCatRank`, `minDisplayRankForObjectClass`).
- **셀 행 클릭**: 행 전체를 `<div>`로 분리해 두어, 행을 눌렀을 때는 체크박스가 바뀌지 않고 **체크박스를 직접 눌렀을 때만** 셀 on/off 됩니다.
- **셀 격자 켠 상태의 지도 클릭**: 지도에서 셀을 눌러도 **표시 on/off는 바꾸지 않고**, 포커스·목록 동기화만 합니다. 셀 표시는 좌측 목록 체크박스에서만 변경합니다.
- **위성 타일 도착**: `renderer.onSatelliteTileReady`에 `requestAnimationFrame`으로 묶어 `draw()` 한 번만 호출해, 여러 타일이 연달아 로드되어도 재렌더 난사를 줄입니다.

### 5.1 3D 지구본 모드

- **`Viewport.auto3D`** 기본값 `true` — 충분히 축소하면 자동으로 orthographic 구체 뷰로 전환되고, 확대하면 머케이터로 복귀합니다. UI 토글은 없으며, 끄려면 콘솔에서 `state.renderer.vp.auto3D = false` 등으로 설정할 수 있습니다.
- 세계 대륙 데이터는 **`assets/ne_110m_land.geojson`** (Natural Earth 110m, 127 폴리곤, ~237 KB)와 **`assets/ne_110m_countries.geojson`** (177 국가 경계, ~709 KB)이 배포에 **기본 탑재**됩니다. globe·머케이터 양쪽 모드 모두 이 동일 데이터를 사용하므로 줌 인/아웃 시 끊김 없이 이어집니다.
- **부드러운 줌(구글어스 UX)**: 휠 한 번이 즉시 폭 점프하지 않고, `smoothZoomTo()`가 목표 scale을 지수 보간(τ ≈ 90 ms)으로 따라갑니다. 휠을 연타하면 진행 중 애니메이션의 목표만 갱신되어 매끄럽게 연속 줌됩니다. 휠 `deltaY` 크기(및 `deltaMode`)에 비례해 log-스케일 배율이 달라져 빠르게 굴릴수록 한 이벤트당 변화가 커집니다. 머케이터는 `zoomAtScreen`으로 커서 아래 지점 유지, 지구본은 `globePickLonLatFromScreen` + `zoomGlobeAtScreen`으로 동일하게 커서 기준 줌합니다.
- 구체 뷰에서 보이는 것:
  - 별이 박힌 검정 배경: **심우주**(화면 전역 작은 별, 지구 디스크만 비움) + 천구 고리(회전에 따라 움직이는 층). 고리 반지름은 화면 모서리까지 넓힘 + 푸른 대기 글로우 + 음영진 바다 디스크.
  - **세계 대륙**(S-52 LANDA 색상표 톤, 어두운 외곽).
  - 15° 간격 위·경도 그리드(적도·자오선 강조).
  - 로드된 ENC 셀의 경계 사각형(가시 셀은 노란 강조, 미가시 셀은 옅은 흰색).
  - 중심을 표시하는 빨간 크로스헤어.
- 머케이터(평면) 모드에서도 동일한 세계 대륙이 배경 레이어로 그려집니다. ENC 면 채움(수심색, 해안선)이 그 위를 덮으므로 차트 데이터가 있는 영역은 ENC 표시를 따르고, **차트 없는 영역(원양·해외)에는 세계 대륙이 그대로 노출**되어 위치 감각을 잃지 않습니다.
- 입력:
  - **드래그**: 지구본을 회전(중심 경·위도 이동).
  - **휠**: 확대/축소. 임계 scale을 지나면 자동으로 머케이터/구체 사이를 전환합니다.
- **원근(perspective) 투영** 으로 구현되어, 줌이 들어올수록 카메라가 표면에 가까워지고 보이는 패치가 점진적으로 평탄해집니다. 이 시점이 머케이터와 거의 일치하므로 전환에서 시각적 점프가 없습니다(구글 어스와 유사한 무단절 줌). `Viewport.projPerspective` / `Viewport.globeCameraDistance` / `Viewport.globeFocalLength` 가 이 거동을 정의합니다. 카메라 거리 `D = 1 + f / scale`(f = `min(canvas폭, 높이) × 0.5`)로, scale → ∞ 면 표면에 접근(평탄), scale → 0 이면 직교투영(전체 지구본).
- **위성 오버레이**: `_renderMercator()` 파이프라인에서만 그립니다. **지구본(globe) 모드**(`_renderGlobe`)일 때는 위성 레이어를 그리지 않습니다. 평면 머케이터로 돌아오면 다시 적용됩니다.
- **버드뷰 보조**: 캔버스를 CSS 3D로 기울일 때(`Renderer.setTilt`), `#stage` 위에 `#sky`(그라데이션 하늘)·`#haze`(거리 안개) 오버레이가 켜져 지평선 너머 깊이감을 냅니다. 툴바에 기울기 슬라이더가 없을 수 있으나 API는 유지됩니다(`#tilt` 요소가 있으면 연결).

### 5.3 위성지도(육지) 오버레이

툴바 **「위성지도」** 체크 시 `renderer.showSatellite = true`가 되고, 머케이터 렌더에서 **면 채움 패스 1 직후(패스 1.5)** 에 위성 타일을 그립니다.

- **타일 소스**: [Esri World Imagery](https://services.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer) XYZ 타일(경로 형식 `…/tile/{z}/{y}/{x}`). API 키 없이 `fetch`(CORS)로 받습니다. 이용 시 Esri·해당 서비스의 이용 약관을 따릅니다.
- **좌표계**: 앱의 해안 투영과 동일한 **Web Mercator** 스케일 관계로 타일을 배치해 별도 워핑 없이 정합합니다.
- **육지에만 표시**: 클립 영역 = **ENC `LNDARE`(육지면)에서 실제로 칠해진 링** ∪ (광역 줌에서만) **Natural Earth 육지**와 화면의 교집합. `_shouldDrawNaturalEarthWorldLand`와 같은 조건으로, 상세 줌에서는 Natural Earth를 클립에 넣지 않아 **개략 육지와 위성이 겹쳐 보이지 않게** 합니다. 뷰포트와 겹치는 ENC 셀이 표시 중이면 Natural Earth 배경 자체를 끄는 정책과 맞물립니다.
- **바다 복구**: 위성이 **항만·만 등 ENC 바다**까지 덮지 않도록, pass 1에서 모은 **바다 `AC` 면(DEPARE 등)** 을 위성 blit **위에** 같은 색으로 다시 칠합니다(거친 `LNDARE` 클립으로 생기는 직선 잘림·청록 격자 오염 방지).
- **캐시**: (1) 메모리 LRU `Map`(`_tileCache`, 상한 약 1500장), (2) 지원 브라우저에서는 **Cache API** `enc-sat-tiles-v1`에 Blob 저장해 재방문 시 네트워크를 줄입니다. `file://` 등 Cache API가 없으면 HTTP 캐시에 의존합니다.
- **부하 제한**: 한 화면에 필요한 타일 수가 **400장을 넘으면** 해당 프레임에서는 위성 그리기를 생략합니다(브라우저 멈춤 방지).
- **지구본**: 위 항목 참고 — 구체 뷰에서는 위성을 그리지 않습니다.

- **전역 디버그**: `window.s52app`으로 `state`, `draw`, `loadFromUrl`, `setCellVisible` 등에 접근할 수 있습니다.
- **CI**: GitHub Actions에서 `npm test` 및 `cell-index` 빌드 등을 실행합니다(`.github/workflows/ci.yml`).
- **터치**: 모바일에서 한 손가락 팬·두 손가락 핀치 줌, 지구본 모드에서의 회전·관성은 `js/main.js`의 포인터 핸들러와 `Viewport`/`Renderer`가 함께 처리합니다(세부는 소스 주석 참고).

## 6. 한계·주의사항

- **완전한 ECDIS S-52 구현은 아닙니다.** 조건부 기호·룩업·패턴·복합선 등은 근사·부분 구현입니다.
- S-57 **업데이트 셀(.001 등)** 은 UI에서 accept 되지만, 이 문서가 다루는 파이프라인은 **기본 셀(.000)** 중심으로 검증된 경우가 많습니다.
- 좌표계는 웹 머캐토르 스타일 투영이며, 공식 해도 표시와 동일한 오차·왜곡 특성을 가집니다.
- 다중 축척 셀 dedup은 휴리스틱(셀 CSCL × 1.5 임계, 24 px 거리)입니다. 매우 가까이 붙은 정상적인 인접 항행보조시설이 한 점으로 합쳐질 가능성이 있으니, 정확한 식별이 필요하면 콘솔에서 `state.renderer.declutter = false` 등으로 끄고 확인하세요(툴바 체크박스는 없음).
- **위성**: 타일 서버 가용성·네트워크·CORS·캐시 용량에 따라 늦게 나타나거나 비어 보일 수 있습니다. 항해 의사결정용 공식 영상이 아닙니다.
