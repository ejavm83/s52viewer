# S-52 ENC Viewer — 코드 설명

브라우저에서 S-57 ENC(`.000`) 셀을 읽고, IHO S-52 표현 규칙에 가깝게 2D 캔버스에 그리는 **정적 웹 뷰어**입니다. 서버는 정적 파일 제공과 셀 인덱스 API 역할만 하며, 파싱·표현·렌더링은 모두 클라이언트 JavaScript(ES 모듈)에서 수행합니다.

**이 문서를 웹 페이지로 보려면** 저장소 루트의 `about.html`을 `npm run serve` 등으로 연 주소에서 여세요(예: `http://localhost:8080/about.html`). `file://`로 직접 열면 브라우저 보안 때문에 마크다운을 불러오지 못할 수 있습니다.

---

## 1. 전체 데이터 흐름

```text
[ENC .000 바이너리]
       ↓
  DDF.parse (iso8211.js)  … ISO 8211 레코드 트리
       ↓
  S57.build (s57.js)      … 피처 목록 + 경위도 기하 + 속성
       ↓
  S52.resolve (s52.js)    … Lookup 매칭 → 그리기 연산(AC/LS/SY/TX/…)
       ↓
  Renderer.render (render.js) … Web Mercator 투영 + 캔버스 2D 드로잉
```

- **셀 목록·범위**: `cell-index.json`(빌드 산출물) 또는 `serve.js`의 `/api/index`가 `000/` 폴더의 `.000` 파일들로부터 경계 박스를 미리 계산합니다(`lib/cell-index.mjs`).
- **실제 도형 데이터**: 사용자가 체크하거나 뷰포트와 겹치는 셀만 `fetch("000/파일명")`으로 불러옵니다(`js/main.js`).

## 3. 모듈별 상세

### 3.1 `js/iso8211.js` — DDF 파서

- ENC 기본 셀은 **ISO 8211** 포맷입니다. DDR(Data Descriptive Record)로 필드 태그·서브필드 레이블·포맷 문자열을 읽고, 이후 각 DR(Data Record)를 같은 스키마로 디코딩합니다.
- `parseFormatControls`가 `(A(2),I(5),2b24,…)` 형태를 펼쳐 서브필드 단위 타입/폭 목록으로 만듭니다.
- `readSubfield`는 고정폭 ASCII(`A`/`I`/`R`), 이진(`b`), 비트열(`B`) 등을 처리합니다.
- 산출물: `ddf.records[]` — 각 원소는 `{ fields: { 태그: [행객체, …] }, order }` 형태입니다.

### 3.2 `js/catalog.js` — 객체·속성 카탈로그

- S-57 파일 안의 `OBJL`, `ATTL` 등은 **숫자 코드**로 저장됩니다.
- `s57objectclasses.csv`, `s57attributes.csv`를 fetch하여 `objClasses`, `attrCodes` 맵을 만듭니다.
- `parseCSV`는 따옴표·쉼표 이스케이프를 고려한 단순 CSV 파서입니다.

### 3.3 `js/s57.js` — S-57 의미 계층

`S57.build(ddf, catalog)`는 대략 다음 두 패스로 동작합니다.

1. **벡터 패스** (`VRID`): `SG2D`/`SG3D` 좌표를 `DSPM.COMF`, `SOMF`로 나누어 도 단위·수심 값으로 환산하고, `VRPT`로 엣지의 시작/끝 노드를 연결합니다.
2. **피처 패스** (`FRID`): `OBJL`·`PRIM`(점/선/면)·`ATTF`/`NATF` 속성·`FSPT` 공간 포인터를 읽어 `features[]`를 만듭니다.

피처 객체 형태(요약):

- `acronym`: 객체 클래스 약어(카탈로그 기준).
- `prim`: 1=점, 2=선, 3=면.
- `attrs`: `{ SCAMIN, DRVAL1, … }` 등 약어 키.
- `geom`: `{ type: "Point"|"Line"|"Area", coords: … }` (경위도 도 단위).
- `soundings`: `[[lon, lat, depth], …]` (해당 시).

면 기하는 `assembleRings`로 엣지 체인을 이어 닫힌 링 배열로 만듭니다. 반환값에는 전 피처를 덮는 `bounds`와 스케일 계수 `comf`, `somf`가 포함됩니다.

### 3.4 `js/s52.js` — S-52 표현 엔진

- `chartsymbols.xml`(OpenCPN이 배포하는 IHO PL 인코딩)을 로드합니다.
- **색상표**(`color-table`), **Lookup**(객체 약어별 조건+지시문), **심볼 비트맵 위치**(아틀라스 내 `x,y,w,h` 및 피벗)를 메모리에 적재합니다.
- `selectLookup(feat, tablePref)`: 기하 타입이 일치하고, `attrib-code` 조건이 가장 잘 맞는 Lookup을 고릅니다(표 이름 선호는 점수에 반영).
- `resolve` → `instruction` 문자열을 `AC`/`AP`/`LS`/`LC`/`SY`/`TX`/`TE`/`CS` 단위로 쪼개 실행해 **내부 draw op 배열**로 변환합니다.

지원·단순화 요약:

- `AP`(영역 패턴)는 **반투명 단색 채움**으로 근사합니다.
- `LC`(복합선)는 **굵은 단색 선**으로 근사합니다.
- `CS(…)`는 `DEPARE`/`SEABED` 수심색, `DEPCNT`, `SOUNDG`, `LIGHTS`, 위험물 일부, `DATCVR`(ENC 커버리지·스케일 경계 윤곽선), `RESARE`, `QUAPOS`/`SLCONS` 등 **시각적으로 중요한 부분집합**만 처리하고, 나머지는 Lookup에 포함된 리터럴 명령에 의존합니다.

색상표 전환은 `setColorTable(name)`으로 `currentTable`을 바꿉니다. 렌더러는 테이블이 바뀌면 피처별 캐시된 해석 결과를 무효화합니다.

### 3.5 `js/render.js` — 캔버스 렌더러

#### 좌표계

- 화면 투영은 **Web Mercator**와 동일한 스케일 관계를 쓰기 위해, X는 **경도(도)를 라디안으로 변환한 값**, Y는 **위도의 등적위형식 `ln(tan(π/4+φ/2))`** 로 캐시합니다. 피처 단위로 한 번만 `mercX`/`mercY`를 적용하고(`_prep`), 매 프레임은 `Viewport.sx`/`sy`의 선형 변환만 수행합니다.

#### `Viewport`

- `fit(bounds)`: 주어진 경위도 박스가 캔버스에 들어가도록 `scale`, 중심 `cx`, `cy` 설정.
- `scaleDenominator()`: 중심 위도·스케일로부터 대략 **1:N 표시 축척**을 추정(SCAMIN·셀 컴파일 스케일 비교에 사용).

#### `Renderer.render()` 파이프라인

1. 배경: S-52 색 `DEPDW`로 전체 클리어.
2. 보이고 로드된 셀의 각 피처에 대해:
   - 옵션에 따라 **SCAMIN** 필터, **표시 범주**(`minDisplayCat`), **원근간략화**(`scaleDisplay` + 셀 `cscl`), 뷰 밖 **바운딩 박스 컬링**, 아주 작은 면/선 **서브픽셀 스킵**.
   - **셀 격자**가 **켜져 있으면** ENC 메타 **`M_COVR`·`M_CSCL`** 을 데이터 경계로 그림(기본 표시범주 Standard에서도 `Other`로 분류된 이 객체들만 예외 허용). **꺼져 있으면** 해당 객체·UI 셀 격자 모두 생략.
   - 색상표가 바뀌지 않았다면 `feat._res`(이미 해석된 ops) 재사용.
3. `DISP_ORDER`에 따른 **우선순위 정렬** 후 패스:
   - **패스 1**: 면 `AC`/`AP` 채움(evenodd).
   - **패스 2**: `LS`를 스타일 키(`색|두께|점선`)별로 묶어 `_strokePolys`로 배치 스트로크.
   - **패스 3**: `SY`(아틀라스 블릿, `ORIENT` 등 회전), `SOUNDG`, `TX`.
4. 옵션 시 셀 **커버리지 격자**(`_drawGrid`).
5. 옵션 시 **경위도 눈금선**(`_drawGraticule`) — 화면 범위에 맞춰 간격 자동 선택(약 18개 전후 눈금, 1.5°·0.5° 등), 소수 자릿수는 간격에 따라 가변.
6. `lastStats`에 그린 수·컬링 수·축척 기록.

#### 성능 관련 구현

- **패닝**: `beginPan`에서 마지막 프레임을 스냅샷 캔버스에 복사하고, 드래그 중에는 `previewPan`으로 **이미지 이동만** 수행해 전체 재계산을 피합니다. 마우스 업 시 전체 `render()`로 복귀합니다.
- **경로 단순화**: `_path`에서 연속 정점이 화면에서 ~1px 이내이면 생략(링의 마지막 점은 유지).
- **라벨·수심**: `declutter` 시 `_place`로 사각형 겹침을 검사해 밀집을 줄입니다.

### 3.6 `js/main.js` — 애플리케이션 조립

- 초기화 순서: `S52.load` → `loadCatalog` → 아틀라스 이미지 → `Renderer` 생성 → `cell-index.json`(실패 시 `/api/index`)으로 그리드·셀 맵 구축 → **전역 경계 `fit`** → `draw` → `?cell=`이 없으면 **뷰포트와 겹치는 셀만** `loadMany`로 병렬(청크 크기 4) 로드·표시.
- **데스크톱·모바일 공통**: 첫 로드는 `namesIntersectingViewport()`에 대해서만 `loadMany`를 호출합니다(전체 ENC 일괄 로드 없음).
- **모바일(768px 이하)**: 팬(마우스/터치)·휠 줌·키보드 이동·**두 손가락 핀치 줌** 후 `scheduleMobileViewportSync`(약 220ms 디바운스)로 다시 `namesIntersectingViewport`에 맞춰 필요한 셀만 로드합니다. 하단 오버레이(`#map-loading`)는 로딩 중에만 표시합니다.
- 셀 바이너리 URL: `000/<셀파일명>` (정적 경로).
- **키보드**: `↑↓←→` 또는 `WASD`로 패닝. 확대·축소는 `KeyboardEvent.code` 기준으로 **`Equal`/`NumpadAdd`**, **`Minus`/`NumpadSubtract`**(즉 `=`·`Shift+=`·숫자패드 `+`/`-` 등 물리 키)로 처리해 레이아웃에 따라 `key`만 다른 경우에도 동작합니다. 화면 중심은 `Viewport.zoomAtScreen`. 셀 검색 등 **텍스트형 `INPUT`**·`TEXTAREA`·`SELECT`에 포커스가 있을 때만 무시합니다.
- 파일 입력·드래그앤드롭: 단일 `.000`를 파싱해 임시 셀로 넣거나 기존 셀을 갱신합니다.
- 쿼리 `?cell=파일명`: 해당 셀을 URL에서 불러 표시(`loadFromUrl`).
- 전역 훅: `window.s52app = { state, loadFromUrl, setCellVisible, draw }` — 콘솔·외부 스크립트에서 디버깅·연동 가능.
- **객체 클래스 탭**: `s57objectclasses.csv`로 영문 클래스명을, `s57objectclasses-ko.csv`로 약어별 한글 표기를 불러와 목록에 병기합니다(필터는 영·한 모두 검색).

## 4. 서버·빌드·배포

### `serve.js`

- 프로젝트 루트를 웹 루트로 서빙합니다.
- `GET /cell-index.json`: 파일이 있으면 그대로, 없으면 런타임에 `buildCellIndex()` 결과를 JSON으로 반환합니다.
- `GET /api/index`: 항상 동적 인덱스.
- `GET /api/cells`: `000/` 내 ENC 관련 파일명 목록.

### `npm` 스크립트 (`package.json`)

- `npm run serve` — 로컬 개발 서버.
- `npm run build` — `cell-index.json` 생성(정적 호스팅에서 Node 없이 인덱스 제공).
- `npm test` — 파서 등 테스트(`test/parse-test.mjs`).

### Vercel (`vercel.json`)

- `buildCommand`: `npm run build`로 인덱스를 미리 생성.
- `outputDirectory`: `.` (저장소 루트 전체를 산출물로 취급).

## 6. 한계·주의사항

- **완전한 ECDIS S-52 구현은 아닙니다.** 조건부 기호·룩업·패턴·복합선 등은 근사·부분 구현입니다.
- S-57 **업데이트 셀(.001 등)** 은 UI에서 accept 되지만, 본 README 범위의 파이프라인은 **기본 셀(.000)** 중심으로 검증된 경우가 많습니다.
- 좌표계는 웹 머캐토르 스타일 투영이며, 공식 해도 표시와 동일한 오차·왜곡 특성을 가집니다.

## 7. 관련 표준·자료(참고)

- IHO S-57(ENC 데이터 구조), IHO S-52(표현 라이브러리).
- ISO/IEC 8211(DDF).
- OpenCPN `chartsymbols.xml` 및 래스터 심볼 PNG, S-57 CSV 카탈로그.

이 문서는 저장소의 현재 코드 구조를 기준으로 작성되었습니다. 동작 변경 시 `js/` 주석과 함께 이 파일을 갱신하는 것을 권장합니다.
