# S-52 ENC Viewer — 코드 설명

**한 줄 요약:** 브라우저에서 ENC 해도를 IHO **S-52** 규칙으로 그리는 벡터 뷰어입니다(`js/main.js`). 넓게 축소하면 **3D 지구본**, 확대하면 **평면(웹 머케이터) 해도**로 자연스럽게 이어집니다. 평면 해도는 **부드러운 팬·줌**을 위해 **서버가 구운 PNG 타일**(OpenLayers)로 표시하고, 지구본·UI·심볼 해석은 모두 브라우저 벡터 엔진이 담당하는 **하이브리드** 구조입니다.

**핵심:** 화면을 두 층으로 나눕니다.
- **무거운 평면 해도** = 서버(또는 디스크 캐시)가 만든 작은 PNG 타일을 OpenLayers가 이어 붙임 → 매 프레임 다시 계산하지 않아 부드럽습니다.
- **지구본·심볼·UI·툴바·셀 목록·ENC 열기** = 기존 브라우저 벡터 앱(`js/main.js`)이 그대로 담당합니다.

평면 타일은 **서버의 `render.js`(node-canvas)** 가, 지구본·벡터 폴백은 **브라우저의 같은 `render.js`** 가 그립니다 — **그리기 코드가 한 벌**이라 양쪽 모양이 일치합니다. 타일 서버가 없으면(정적 호스팅 등) 자동으로 **순수 벡터**로 폴백합니다.

**이 문서를 웹 페이지로 보려면** `about.html`을 서버로 연 주소에서 여세요(예: `http://localhost:8000/about.html`). `file://`로만 열면 마크다운을 못 불러올 수 있습니다.

## 빠른 이해 (여기만 읽어도 됩니다)

### 1) 두 층으로 나눈 하이브리드 렌더링

```text
       [ 브라우저 ]                              [ 서버(또는 디스크 캐시) ]
  js/main.js  (벡터 앱)
   ├ 툴바·셀목록·ENC열기·오브젝트 패널
   ├ 3D 지구본 (축소)            ────그림────►  (브라우저가 직접 그림)
   └ 평면 해도 (확대)
        │ renderer.tileMode = true
        │ → 평면 벡터 그리기 생략(캔버스 투명)
        ▼
  js/tile-mercator.js  ──URL 미러링──►  GET /tile/{z}/{x}/{y}.png?p=…&sv=…
   └ #chart 아래에 OpenLayers 타일 지도(#olmap)            │
        ▲                                                   ▼
        └────── PNG 타일을 이어 붙여 표시 ◄──── serve.js: 캐시 있으면 파일,
                                                  없으면 render.js(node-canvas)로 굽고 저장
```

- **확대(평면)**: `#chart` 캔버스는 투명해지고, 그 아래 OpenLayers가 **서버 PNG 타일**을 보여 줍니다.
- **축소(지구본)**: OpenLayers를 숨기고, `#chart` 캔버스의 **벡터 3D 지구본**을 보여 줍니다.
- 둘 사이는 기존 벡터 앱의 부드러운 줌이 그대로 이어지며, **툴바·셀 목록·상태바**는 항상 벡터 앱이 구동합니다.

### 2) 빠른 이유 (속도 기법)

| 구분 | 무엇을 하나요? | 왜 빨라지나요? |
|------|----------------|----------------|
| **타일 + 디스크 캐시** | 평면 화면을 작은 정사각 PNG(줌·타일 좌표마다 한 장)로 나눕니다. 한 번 그린 타일은 `tiles/` 폴더에 저장해 두었다가 **다음 요청에는 파일만 읽습니다**. | 같은 화면을 매번 처음부터 다시 계산하지 않습니다. |
| **동시 요청 합치기** | 서버가 같은 타일을 여러 번 동시에 요청받으면 **한 번만 그리고** 나머지는 그 결과를 공유합니다(coalesce). | CPU 낭비·중복 작업을 줄입니다. |
| **브라우저는 이미지만 합성** | 평면에서 팬·줌할 때는 **이미 만들어진 타일**을 옮기고 확대/축소합니다(OpenLayers). | 브라우저가 S-52 전체를 매 프레임 다시 돌리지 않습니다. |
| **서버 메모리 (셀 LRU)** | ENC 셀을 파싱해 두는 양에 상한을 두고, 오래 안 쓴 셀은 메모리에서 비웁니다. | 셀이 매우 많을 때 서버가 메모리로 터지는 것(OOM)을 막습니다. |
| **기동 시 예열** | 서버가 뜰 때 엔진(S-52·카탈로그·아틀라스 등)을 미리 올려 둡니다(`warmup`). | **첫 타일 요청**이 덜 버벅입니다. |
| **미리 굽기(예열)** | `scripts/prerender-*.mjs`로 관심 지역·줌의 타일을 미리 생성합니다(예: 한국 전역 z5–14). | 실제로 지도를 켤 때 **첫 화면·이동**이 거의 즉시입니다. |
| **그리기 엔진 안쪽** (`js/render.js`) | 머케이터 좌표·심볼 해석 결과를 피처 단위로 캐시하고, 화면 밖은 그리지 않으며, 점·선은 픽셀 기준으로 **덜 촘촘한 정점만** 씁니다. | 한 타일 안에서도 불필요한 연산을 줄입니다. |

정리하면 **“무거운 평면 해도는 서버(또는 디스크 캐시) / 가벼운 붙이기·지구본·UI는 브라우저”** 로 나눈 것이 체감 속도의 핵심입니다. (기술 상세는 아래 **§1**, **§3.5**, **§3.7**.)

### 3) IHO S-52 표준에 맞춘 부분

이 뷰어는 표현을 **IHO S-52 Presentation Library 4.0** 에 맞추려 노력했고, 상용 ECDIS(예: CARIS Easy View)와 같은 모양을 목표로 합니다.

- **색상(팔레트)** — `js/s52-preslib-colors.js`의 **PresLib 4.0 표준 색표**(주·박명·야 등 5종)로, `chartsymbols.xml` 로드 직후 색을 덮어써 표준값에 정렬합니다. 예: 깊은물 `DEPDW`, 보통물 `DEPMD`, 얕은물 `DEPVS`, 간조노출 `DEPIT`, 육지 `LANDA` 등.
- **수심 숫자(SOUNDG)** — 정수부는 크게, **데시미터(소수 한 자리)는 작은 아래첨자**로, **건출고(간조 시 드러나는 높이, 음수 수심)** 는 **양수로 표기하고 밑줄**을 그어 구분합니다(S-52 관행).
- **수심 등고선(안전 윤곽)** — 기본 임계를 **얕음 2 m · 안전 30 m · 깊음 50 m** 로 두어, 연안의 30 m 미만 수역이 `DEPMS`(파랑)로 칠해져 일반 ECDIS와 같은 모습이 됩니다.

(자세한 동작은 **§3.4**·**§3.5**, 표준 색표 생성은 **§3.8** 참고.)

### 4) 지금 화면(`index.html`)에서의 동작·한계

`index.html`은 **벡터 앱(`js/main.js`) + 하이브리드 타일(`js/tile-mercator.js`)** 입니다. 대부분의 기능이 **그대로 동작**합니다.

- ✅ **3D 지구본 ↔ 평면 자동 전환**, 부드러운 줌, 키보드 뷰 즐겨찾기(Ctrl+1 등).
- ✅ **ENC 파일·폴더 열기**, **셀 목록**(검색·fly-to·체크 on/off), **셀 격자**, **오브젝트(클래스) 패널**.
- ✅ **색상표·표시범주** — 벡터(지구본)와 타일 URL **양쪽에 동시 반영**됩니다.
- ℹ️ **완전한 ECDIS S-52는 아닙니다.** 조건·패턴·일부 기호는 근사·부분 구현입니다(항해 의사결정용 공식기 아님).


## 1. 전체 데이터 흐름

### 1.1 기본: 하이브리드 (`index.html` = `main.js` + `tile-mercator.js`)

`index.html`은 **벡터 앱**을 띄운 뒤, `tile-mercator.js`가 그 위에 **평면 타일 층**을 얹습니다.

```text
[벡터 앱 main.js]  ── 평면(머케이터) ──►  renderer.tileMode = true
   │                                       └ render.js: 평면 벡터 그리기 생략(#chart 투명)
   │                                          (지구본 _renderGlobe 은 영향 없음 → 벡터로 계속 그림)
   ▼
[tile-mercator.js]  매 프레임 vp(뷰포트) → OpenLayers 뷰로 미러링
   │   • 평면·전환:  #olmap 표시(투명 캔버스 아래로 타일이 비침)
   │   • 지구본:     #olmap 숨김(캔버스의 벡터 지구본 표시)
   ▼
[OpenLayers XYZ]  GET /tile/{z}/{x}/{y}.png?p=<팔레트>&sv=<스타일버전>[&disp=…]
```

- **타일 서버 주소**: `<meta name="enc-tile-base">`. **비우면 동일 출처**(로컬 `serve.js`), 별도 서버면 그 절대 URL(예: `https://s52-tiles.onrender.com`). CORS를 위해 서버는 `Access-Control-Allow-Origin: *`로 응답합니다.
- **가용성 프로브 → 폴백**: 시작 시 `new Image()`로 견본 타일 1장을 받아 봅니다(약 22초 타임아웃). **도달하면** 타일 모드를 켜고, **안 되면**(정적 호스팅 등 `/tile` 없음) `tileMode`를 켜지 않아 **순수 벡터 렌더가 그대로** 동작합니다.
- **설정 동기화**: 툴바의 **색상표**(`palette`)·**표시범주**(`dispcat`)는 벡터 렌더러(`renderer.s52.currentTable`, `renderer.minDisplayCat`)를 바꾸고, `tile-mercator.js`가 이를 관찰해 **타일 URL의 `p`·`disp` 쿼리**를 갱신합니다 → 지구본과 타일이 **같은 팔레트·범주**로 보입니다.
- **캐시 무효화(`sv`)**: 타일 URL에 **`sv=<STYLE_VERSION>`**(현재 `3`)을 붙입니다. 서버 응답이 `Cache-Control: immutable`이라 URL이 같으면 브라우저/CDN이 **옛 타일을 계속** 보여 주므로, 색·심볼·등고선 등 렌더가 바뀌면 이 숫자를 올려 새 URL로 강제합니다.
- **줌 시 깜빡임 방지**: OL 소스 `transition: 0`(타일 페이드 끔)·레이어 `preload: 6`(상위 줌 타일 미리 로드)으로 빈 프레임을 줄입니다. OL 줌은 `#scale-bar`/`#zoom-ctrl` 등 **기존 UI**가 구동하며 OL 기본 컨트롤은 숨깁니다.

### 1.2 평면 타일 1장이 만들어지는 길 (서버)

```text
[ENC .000 … 서버 디스크 000/]
       ↓ (타일 요청 시, 디스크 캐시 미스)
  DDF.parse → S57.build → S52.resolve → Renderer._renderMercator (render.js, node-canvas)
       ↓
  PNG  →  디스크 tiles/<설정키>/z/x/y.png  (serve.js가 저장)
       ↓
  브라우저: OpenLayers XYZ 레이어가 GET /tile/z/x/y.png?… 로 합성
```

- **타일 URL**: `serve.js`가 `GET /tile/{z}/{x}/{y}.png`를 처리합니다. 쿼리로 **팔레트**(`p=day|dusk|night`), **표시범주**(`disp=base|standard|other`), 수심 등고선 임계(`shallow`·`safety`·`deep`), **`scamin=0`**(SCAMIN 무시) 등을 바꿀 수 있습니다. 설정 조합마다 **다른 디스크 하위 폴더**(`tiles/day`, 기본이 아니면 `tiles/day__other_…` 등)에 캐시되어 같은 요청은 재렌더 없이 제공됩니다. **기본값**(주간·Standard·등고선 2/30/50)은 `tiles/day/`에 저장됩니다.

### 1.3 벡터 본체 (`js/main.js`) — 지구본·UI·폴백 모두 담당

평면 타일을 빼면 나머지는 전부 벡터 앱의 일입니다.

```text
[ENC .000 바이너리]
       ↓
  DDF.parse (iso8211.js)  … ISO 8211 레코드 트리
       ↓
  S57.build (s57.js)      … 피처 목록 + 경위도 기하 + 속성
       ↓
  S52.resolve (s52.js)    … Lookup 매칭 → 그리기 연산(AC/LS/SY/TX/…)
       ↓
  Renderer.render (render.js) … 지구본 / 평면 머케이터 / 패닝 프리뷰 …
```

- **셀 목록·범위**: `cell-index.json`(빌드 산출물) 또는 `serve.js`의 `/api/index`가 `000/` 폴더의 `.000` 파일들로부터 경계 박스와 컴파일레이션 스케일(CSCL)을 미리 계산합니다(`lib/cell-index.mjs`).
- **좌측 셀 목록**: 인덱스의 `.000`을 폴더 트리로 보여 주고, 검색창은 **이름·경로 문자열**로 거릅니다. 행 순서는 고정이며, 현재 지도 뷰와 겹치지 않는 셀 행만 **흐리게** 표시합니다(`syncCellListInViewportHighlight`, `namesIntersectingViewport`). **체크박스**는 셀 표시 on/off, **행 클릭**은 해당 셀 범위로 뷰 이동입니다.
- **실제 도형 데이터**: 사용자가 체크하거나 뷰포트와 겹치는 셀만 `fetch("000/파일명")`으로 불러옵니다.

> **타일 vs 벡터의 차이 한 줄:** 타일 모드는 평면 해도를 **“그림 한 장”** 으로 보여 주므로, 셀 체크박스·오브젝트 on/off 같은 **객체 단위 토글이 평면 그림에는 즉시 반영되지 않습니다**(타일은 서버가 `000/` 전체로 굽습니다). 객체 단위로 끄고 켜며 확인하려면 타일 서버 없이(=벡터 폴백) 보거나, 콘솔에서 `tileMode`를 끄세요.

## 2. 디렉터리와 역할

문서 맨 위 **「빠른 이해 §5」** 의 **폴더 트리**를, 여기서는 파일·역할 표로 풀어 씁니다.

## 3. 모듈별 상세

### 3.1 `js/iso8211.js` — DDF 파서

- ENC 기본 셀은 **ISO 8211** 포맷입니다. DDR(Data Descriptive Record)로 필드 태그·서브필드 레이블·포맷 문자열을 읽고, 이후 각 DR(Data Record)를 같은 스키마로 디코딩합니다.
- `parseFormatControls`가 `(A(2),I(5),2b24,…)` 형태를 펼쳐 서브필드 단위 타입/폭 목록으로 만듭니다.
- `readSubfield`는 고정폭 ASCII(`A`/`I`/`R`), 이진(`b`), 비트열(`B`) 등을 처리합니다.
- 산출물: `ddf.records[]` — 각 원소는 `{ fields: { 태그: [행객체, …] }, order }` 형태입니다.

### 3.2 `js/catalog.js` — 객체·속성 카탈로그

- S-57 파일 안의 `OBJL`, `ATTL` 등은 **숫자 코드**로 저장됩니다.
- `s57objectclasses.csv`, `s57attributes.csv`를 fetch하여 `objClasses`, `attrCodes` 맵을 만듭니다.
- `parseCSV`는 따옴표·쉼표 이스케이프를 고려한 단순 CSV 파서입니다.

### 3.3 `js/s57.js` — S-57 의미 계층

`S57.build(ddf, catalog)`는 대략 다음 두 패스로 동작합니다.

1. **벡터 패스** (`VRID`): `SG2D`/`SG3D` 좌표를 `DSPM.COMF`, `SOMF`로 나누어 도 단위·수심 값으로 환산하고, `VRPT`로 엣지의 시작/끝 노드를 연결합니다.
2. **피처 패스** (`FRID`): `OBJL`·`PRIM`(점/선/면)·`ATTF`/`NATF` 속성·`FSPT` 공간 포인터를 읽어 `features[]`를 만듭니다.

피처 객체 형태(요약):

- `acronym`: 객체 클래스 약어(카탈로그 기준).
- `prim`: 1=점, 2=선, 3=면.
- `attrs`: `{ SCAMIN, DRVAL1, … }` 등 약어 키.
- `geom`: `{ type: "Point"|"Line"|"Area", coords: … }` (경위도 도 단위).
- `soundings`: `[[lon, lat, depth], …]` (해당 시).

면 기하는 `assembleRings`로 엣지 체인을 이어 닫힌 링 배열로 만듭니다. 반환값에는 전 피처를 덮는 `bounds`와 스케일 계수 `comf`, `somf`가 포함됩니다.

### 3.4 `js/s52.js` — S-52 표현 엔진

- `chartsymbols.xml`(OpenCPN이 배포하는 IHO PL 인코딩)을 로드합니다.
- **색상표**(`color-table`), **Lookup**(객체 약어별 조건+지시문), **심볼 비트맵 위치**(아틀라스 내 `x,y,w,h` 및 피벗)를 메모리에 적재합니다.
- **표준 색 정렬**: `load()`에서 `chartsymbols.xml` 색을 파싱한 직후 `_applyPreslibColors()`가 **`js/s52-preslib-colors.js`의 PresLib 4.0 값으로 덮어씁니다.** OpenCPN 배포본의 미세한 색차를 표준값(상용 ECDIS와 동일)에 맞추기 위함입니다.
- **수심 등고선 기본값**: 생성자에서 `shallow=2`, `safety=30`, `deep=50`. 안전 윤곽(30 m)을 기준으로 연안 수역이 파랑(`DEPMS`)으로 칠해집니다.
- `selectLookup(feat, tablePref)`: 기하 타입이 일치하고, `attrib-code` 조건이 가장 잘 맞는 Lookup을 고릅니다(표 이름 선호는 점수에 반영).
- `resolve` → `instruction` 문자열을 `AC`/`AP`/`LS`/`LC`/`SY`/`TX`/`TE`/`CS` 단위로 쪼개 실행해 **내부 draw op 배열**로 변환합니다.
- `S52.displayCatRank` / `minDisplayRankForObjectClass`: Lookup의 `display-cat`로 객체 클래스를 Base·Standard·Other 구간으로 묶을 때 사용(오브젝트 사이드바). `DEPCNT`는 PL이 Other인 경우가 많아 **Standard 구간**으로 고정합니다.

지원·단순화 요약:

- `AP`(영역 패턴)는 **반투명 단색 채움**으로 근사합니다.
- `LC`(복합선)는 **굵은 단색 선**으로 근사합니다.
- `CS(…)`는 `DEPARE`/`SEABED` 수심색, `DEPCNT`, `SOUNDG`, `LIGHTS`, 위험물 일부, `DATCVR`(ENC 커버리지·스케일 경계 윤곽선), `RESARE`, `RESTRN01`(ACHARE), `QUAPOS`/`SLCONS` 등 **시각적으로 중요한 부분집합**만 처리하고, 나머지는 Lookup에 포함된 리터럴 명령에 의존합니다.

색상표 전환은 `setColorTable(name)`으로 `currentTable`을 바꿉니다(이때도 PresLib 표준값 유지). 렌더러는 테이블이 바뀌면 피처별 캐시된 해석 결과를 무효화합니다.

### 3.5 `js/render.js` — 캔버스 렌더러 (브라우저 + 서버 공용)

**브라우저 벡터 뷰**와 **`lib/render-tile.mjs`(서버 타일)** 가 **같은 `Renderer` 클래스**를 사용합니다. 차이는 다음과 같습니다.

- **벡터 뷰(브라우저)**: `render()` 전체(지구본 전환, 패닝 프리뷰, `lastStats` 등)와 사용자 인터랙션에 맞춘 `Viewport`가 중심입니다.
- **서버 타일**: 타일 bbox에 맞춰 `Viewport`의 `scale`·`cx`·`cy`만 설정하고 **`_renderMercator()` 한 번**으로 머케이터 패스만 그립니다. Natural Earth 오버레이·지구본은 끕니다(`getRenderer` 참고).

#### `tileMode` 플래그 (하이브리드 핵심)

- 브라우저에서 `tile-mercator.js`가 `renderer.tileMode = true`로 켭니다.
- 켜지면 **평면 머케이터 경로**(`_renderMercator`, `previewPan`, 스냅샷 프리뷰, 전환 크로스페이드)가 **검정 채움 대신 `clearRect`로 캔버스를 투명**하게 두고 일찍 반환합니다 → 아래의 OpenLayers 서버 타일이 비쳐 보입니다.
- **지구본 경로(`_renderGlobe`)는 영향받지 않습니다** — 축소 시 벡터 지구본이 그대로 그려지고, `tile-mercator.js`가 그때 `#olmap`을 숨깁니다.

#### 좌표계

- 화면 투영은 **Web Mercator**와 동일한 스케일 관계를 쓰기 위해, X는 **경도(도)를 라디안으로 변환한 값**, Y는 **위도의 등각형식 `ln(tan(π/4+φ/2))`** 로 캐시합니다. 피처 단위로 한 번만 `mercX`/`mercY`를 적용하고(`_prep`), 매 프레임은 `Viewport.sx`/`sy`의 선형 변환만 수행합니다.

#### `Viewport`

- `fit(bounds)`: 주어진 경위도 박스가 캔버스에 들어가도록 `scale`, 중심 `cx`, `cy` 설정.
- `scaleDenominator()`: 중심 위도·스케일로부터 대략 **1:N 표시 축척**을 추정(SCAMIN·SCAMAX·셀 컴파일 스케일 비교, 동적 폰트 크기 결정에 사용).
- `auto3D`(기본 `true`): 충분히 축소하면 직교/원근 구체(지구본)로, 확대하면 머케이터로 자동 전환.

#### `Renderer.render()` 파이프라인 (머케이터 패스 기준)

1. 배경: S-52 색 `DEPDW`로 전체 클리어. (단, **`tileMode`면 투명 클리어 후 종료** — 서버 타일이 대신함.)
2. 다음 프레임-스코프 자료구조를 초기화합니다:
   - 라벨 박스 충돌 인덱스(`_labelBoxes`)
   - 통항·조류 화살표 디클러터 격자(`_flowArrowGrid`, Map)
   - 항행보조시설 dedup 격자(`_pointSymbolGrid`, Map)
   - 동적 폰트 크기(`_labelFontPx`, `_soundingFontPx`) — `denom`의 로그에 비례하여 9 ~ 16 px 사이에서 결정
3. 보이고 로드된 셀의 각 피처에 대해:
   - 옵션에 따라 **SCAMIN**·**SCAMAX**(표시 분모 `denom`과 비교), **표시 범주**(`minDisplayCat`), **원근간략화**(`scaleDisplay` + 셀 `cscl`), 뷰 밖 **바운딩 박스 컬링**, 아주 작은 면/선 **서브픽셀 스킵**.
   - OpenCPN `chartsymbols.xml`에서 **DEPCNT**(및 선형 **DEPARE**) 룩업의 `display-cat`이 `Other`로만 정의된 경우가 있어, Standard 뷰에서 수심 등고선이 사라지지 않도록 `depthContourStandardDisplay`로 필터 시에만 **Standard와 동등**으로 취급합니다.
   - **셀 격자**가 켜져 있으면 ENC 메타 **`M_COVR`·`M_CSCL`** 을 데이터 경계로 그립니다(꺼져 있으면 생략).
   - 색상표가 바뀌지 않았다면 `feat._res`(이미 해석된 ops) 재사용.
   - resolved 엔트리에 셀 CSCL(`cellCscl`)을 같이 기록 — 패스 3의 다중 축척 우선순위 판정에 사용.
4. 화면 안에 들어오는 모든 셀의 (Mercator) 경계 박스와 CSCL을 모은 **`navaidCells` 인덱스**를 만들고, `_bestCsclAt(mx, my)`로 임의 위치에서의 **가장 상세한(가장 작은) CSCL** 을 즉시 조회할 수 있게 합니다.
5. `DISP_ORDER`에 따른 **우선순위 정렬** 후 패스:
   - **패스 1**: 면 `AC`/`AP` 채움(evenodd). 다중 축척에서 개략 셀은 `_supersededByFinerForExtent`(모서리+중심)로만 생략하고 **CSCL 거친→상세** 순으로 칠합니다. `LNDARE`(육지면)는 동일 순서로 겹쳐 상세 ENC 육지가 위에 오게 합니다.
   - **패스 2**: `LS`를 스타일 키(`색|두께|점선`)별로 묶어 `_strokePolys`로 배치 스트로크.
   - **패스 3**: `SY`(아틀라스 블릿, `ORIENT` 등 회전), **`SOUNDG`(§아래)**, `TX`.
     - **다중 축척 셀 우선순위 필터**: `declutter` 시, 피처가 속한 셀의 CSCL이 그 위치의 최상세 CSCL × 1.5보다 더 개략이면 `SY`/`SOUNDG`를 건너뜁니다.
     - **항행보조 dedup**: 부이(`BOY*`)·비컨(`BCN*`)·`LIGHTS`(색 기준) 등은 화면상 24 px 이내에 같은 그룹이 이미 그려졌으면 건너뜁니다.
     - **방향 화살표 dedup**: TSS·항로·추천항적·조류 화살표는 64 px 거리 기반으로 솎습니다.
     - **장애물 점심볼(광역)**: 약 1:4.5만 이상 축소 뷰에서만 `ISODGR`·`OBSTRN`·`WRECKS`·`UWTROC` 계열을 픽셀 격자로 띄엄 그려 연안 과밀을 완화합니다.
6. 옵션 시 셀 **커버리지 격자**(`_drawGrid`), **경위도 눈금선**(`_drawGraticule`).
7. **좌하단 축척 바**(`#scale-bar`)와 `lastStats`(그린 수·컬링 수·축척) 갱신.

#### 수심 숫자(SOUNDG) — S-52 표준 표기

- `_soundings(feat)`는 각 수심값을 **정수부 + 데시미터부**로 나눠 그립니다. 정수부는 기준 폰트(`fpx`), **데시미터(소수 첫 자리)는 약 0.72배 크기로 살짝 내려** 아래첨자처럼 붙입니다(`soundingParts`).
- **건출고(drying height)**: 수심이 **음수**면 간조 시 드러나는 높이로 보아 **부호 없이 절댓값**으로 적고 **숫자 아래 밑줄**을 그어 표시합니다(S-52 관행). 단위는 `depthUnit`(기본 m).

#### 성능 관련 구현

- **서버 타일(`renderTile`)**: 한 타일 PNG만 만들면 되므로 패닝 프리뷰·오프스크린 캐시를 쓰지 않습니다. 반복 요청은 **디스크 캐시**(`tiles/…`)로 상쇄됩니다.
- **패닝(벡터 뷰)**: `beginPan`에서 마지막 프레임을 스냅샷 캔버스에 복사하고, 드래그 중에는 `previewPan`으로 **이미지 이동만** 수행해 전체 재계산을 피합니다(`tileMode`면 투명 처리). 마우스 업 시 전체 `render()`로 복귀합니다.
- **경로 단순화**: `_path`에서 연속 정점이 화면에서 ~1px 이내이면 생략(링의 마지막 점은 유지).
- **라벨·수심**: `declutter` 시 `_place`로 사각형 겹침을 검사해 밀집을 줄입니다.
- **동적 폰트**: 라벨·사운딩 폰트 크기는 현재 표시 축척(`denom`)의 로그에 따라 자동 조절.

### 3.6 `js/main.js` — 벡터 앱 본체 (현재 `index.html`이 로드)

`index.html`은 `main.js`를 **모듈로 로드**합니다. 타일 층은 `tile-mercator.js`가 그 위에 얹지만, **툴바·셀 목록·ENC 열기·지구본·즐겨찾기·상태바**는 전부 여기서 구동됩니다.

- 초기화 순서: `S52.load` → `loadCatalog` → 아틀라스 이미지 → `Renderer` 생성 → `cell-index.json`(실패 시 `/api/index`)으로 그리드·셀 맵 구축 → **전역 경계 `fit`** → `draw` → `?cell=`이 없으면 **데스크톱만** 뷰포트와 겹치는 셀을 `loadMany`로 병렬(청크 4) 로드·표시.
- **데스크톱**: 첫 로드는 `namesIntersectingViewport()`에 대해서만 `loadMany`를 호출합니다(전체 ENC 일괄 로드 없음).
- **모바일(768px 이하)**: 초기에는 ENC를 자동으로 받지 않고, **팬·줌(또는 `?cell=`)** 이 있을 때만 `scheduleMobileViewportSync`(약 220ms 디바운스) → `flushMobileViewportSync`에서 필요한 셀을 로드합니다. 하단 오버레이(`#map-loading`)는 로딩 중에만 표시합니다.
- 셀 바이너리 URL: `000/<셀파일명>` (정적 경로).
- **ENC 열기 통합 메뉴**: 툴바의 `ENC 열기 ▾` 한 버튼으로 **파일 다중 선택**과 **폴더 일괄 선택**을 모두 지원합니다. 폴더 선택은 `webkitdirectory` 지원 브라우저에서만 활성화됩니다.
- **키보드 단축키**:
  - `↑↓←→` / `WASD`: 화면 패닝.
  - `Equal`/`NumpadAdd` · `Minus`/`NumpadSubtract`: 확대/축소(`KeyboardEvent.code` 기준).
  - `1`~`9`: 해당 번호로 저장된 뷰포트(중심·축척) 복원.
  - `Ctrl+1`~`Ctrl+9`: 현재 뷰포트를 해당 번호 슬롯에 저장(`localStorage` `encViewerBookmarks`).
  - 텍스트형 `INPUT`·`TEXTAREA`·`SELECT`에 포커스가 있을 때만 무시합니다.
- 파일 입력·드래그앤드롭: 단일 `.000`을 파싱해 임시 셀로 넣거나 기존 셀을 갱신합니다.
- 쿼리 `?cell=파일명`: 해당 셀을 URL에서 불러 표시(`loadFromUrl`).
- 전역 훅: `window.s52app = { state, loadFromUrl, setCellVisible, draw }` — 콘솔·외부 스크립트(예: `tile-mercator.js`)에서 사용.
- **사이드바 탭**: **셀** — 폴더 트리·검색·보이는 영역 표시/숨김/전체보기. **오브젝트** — 로드된 ENC의 객체 클래스(약어)별 건수·표시 on/off(`renderer.hiddenClasses`). 클래스 설명은 `s57objectclasses.csv`(영문)·`s57objectclasses-ko.csv`(한글)로 병기하고 **영문·한글 모두** 검색됩니다. 목록은 `display-cat` 기반 **Display Base / Standard / Other** 구간으로 나뉩니다.
  > 단, **타일 모드의 평면 그림**은 서버가 굽는 “한 장 이미지”라 오브젝트 on/off가 평면에 즉시 반영되지 않습니다(지구본·벡터 폴백에는 반영).

### 3.7 `lib/render-tile.mjs` + `serve.js` 타일 엔드포인트

- **역할**: Web Mercator **EPSG:3857 XYZ** 한 칸(`z`,`x`,`y`)에 해당하는 경위도 bbox를 구하고, 그 영역과 겹치는 ENC 셀만 `000/`에서 읽어 파싱·투영한 뒤, **`Renderer._renderMercator()`** 로 **정사각 캔버스**(기본 256×256)에 그려 **PNG 버퍼**를 반환합니다.
- **브라우저 shim**: 서버에서 `render.js` 등을 그대로 쓰기 위해 `globalThis.fetch`(디스크 자산), `DOMParser`(linkedom — `s52.js`가 `querySelectorAll`을 쓰므로 필요), `document.createElement("canvas")`(node-canvas)를 import 전에 주입합니다.
- **엔진 캐시**: `S52`·카탈로그·아틀라스 3종·`cell-index.json`(없으면 `buildCellIndex()`)은 한 번만 적재합니다(`getEngine`, `warmup`).
- **셀 LRU**: 파싱된 셀 데이터는 상한(`CELL_CACHE_MAX`)을 넘기면 밀려납니다. 전역 ENC가 많을 때 OOM을 피하기 위함이며, 512MB급 호스트(`RENDER=true`)에서는 기본 상한을 더 낮춥니다.
- **팔레트·표시범주·등고선 적용**: `renderTile`이 요청마다 `setColorTable`·`minDisplayCat`을 세팅하고, 등고선(`shallow/safety/deep`, 기본 2/30/50)이 바뀌면 `invalidateResCache()`로 캐시 셀의 해석을 무효화해 다음 렌더에서 재해석되게 합니다.
- **`serve.js`**: `GET /tile/{z}/{x}/{y}.png`에서 `tileSettings()`로 쿼리를 구조체로 바꾼 뒤, 디스크 캐시 파일이 있으면 즉시 반환하고, 없으면 동일 키에 대한 **동시 요청을 coalesce**한 뒤 `renderTile` → `tiles/<설정키>/…` 저장 → 응답합니다. 응답에 **CORS(`Access-Control-Allow-Origin: *`)** 와 `Cache-Control: immutable`을 둡니다. 동시 렌더 수는 `RENDER` 등 환경변수로 제한할 수 있습니다.

### 3.8 표준 색표 정렬 — `js/s52-preslib-colors.js` + `scripts/extract-preslib-colors.mjs`

- **무엇**: IHO **S-52 Presentation Library 4.0** 의 공식 색값을 팔레트별(DAY_BRIGHT/DAY_BLACKBACK/DAY_WHITEBACK/DUSK/NIGHT)로 담은 표입니다. `s52.js`가 `chartsymbols.xml` 로드 직후 이 값으로 색을 덮어써, OpenCPN 배포본의 미세한 색차를 **표준(상용 ECDIS와 동일)** 에 맞춥니다.
- **왜**: 같은 ENC라도 렌더러마다 수심색·육지색이 조금씩 달라 보일 수 있는데, 표준 색표로 고정하면 **CARIS Easy View 등과 동일한 톤**이 됩니다.
- **생성**: `scripts/extract-preslib-colors.mjs`가 CARIS의 `colcalib/*.xml`(주/박명/야 보정표)에서 색을 읽어 이 파일을 자동 생성합니다. 색 기준이 바뀌면 스크립트를 다시 돌립니다.

## 4. 서버·빌드·배포

### `serve.js`

- 프로젝트 루트를 웹 루트로 서빙합니다.
- `GET /cell-index.json`: 파일이 있으면 그대로, 없으면 런타임에 `buildCellIndex()` 결과를 JSON으로 반환합니다.
- `GET /api/index`: 항상 동적 인덱스. `GET /api/cells`: `000/` 내 ENC 관련 파일명 목록.
- **`GET /tile/{z}/{x}/{y}.png`**: 위 **§3.7**. `node-canvas` 미설치 등으로 엔진이 없으면 500이 날 수 있습니다.
- `/health` 헬스 체크, favicon 폴백, 정적 경로 보안 정리 등을 포함합니다.

### 타일 사전 생성(선택)

- `scripts/prerender-tiles.mjs` — 관심 bbox·줌 범위에 대해 `renderTile`을 반복 호출해 `tiles/`를 채웁니다.
- `scripts/prerender-coverage.mjs` — 인덱스의 셀별 CSCL에 맞는 줌으로 타일 집합을 넓게 예열합니다(예: 한국 전역 z5–14).
- `scripts/prerender-all.mjs` — 일괄·조합 예열용.

> **스타일이 바뀌면**(색·심볼·사운딩·등고선): ① `tile-mercator.js`의 `STYLE_VERSION`을 올려 브라우저/CDN 캐시를 무효화하고, ② 서버의 `tiles/` 캐시를 비우거나(또는 재배포로 디스크 초기화) 다시 예열합니다.

### `npm` 스크립트 (`package.json`)

- `npm run serve` — 로컬 개발/타일 서버.
- `npm run build` — `cell-index.json` 생성(정적 호스팅에서 Node 없이 인덱스 제공).
- `npm test` — 파서 등 테스트.

### 배포 형태

- **정적 앱(Vercel 등)** — `index.html`·`js/`·`assets/`·`000/`를 그대로 호스팅. 이 경우 `/tile`이 없으므로 `tile-mercator.js`가 프로브에 실패해 **순수 벡터**로 동작합니다.
- **타일 서버(별도)** — `node-canvas` 네이티브 라이브러리·한글 폰트·힙 상한이 필요해 **Docker**(`Dockerfile`)로 띄우는 것을 권장합니다. 띄운 뒤 정적 앱의 `<meta name="enc-tile-base">`에 그 URL을 넣으면 평면이 서버 타일로 바뀝니다. 이것이 레퍼런스 사이트(서버가 해도를 래스터로 굽고 클라이언트는 이미지만 합성)와 같은 구조입니다.
- **로컬/사내망** — `npm run serve` 한 대로 정적+타일을 모두 제공(`enc-tile-base` 비움 = 동일 출처).

### 5.1 3D 지구본 ↔ 평면 전환

`index.html`은 **하이브리드**라 지구본·머케이터 자동 전환이 **그대로 동작**합니다. 지구본은 벡터(`#chart`), 평면은 타일(`#olmap`)로 표시되며 그 사이를 끊김 없이 줌합니다.

- **`Viewport.auto3D`**(기본 `true`): 충분히 축소하면 자동으로 구체(지구본), 확대하면 머케이터로 복귀합니다. 콘솔에서 `state.renderer.vp.auto3D = false`로 끌 수 있습니다.
- 세계 대륙은 **`assets/ne_110m_land.geojson`**(Natural Earth 110m)와 **`assets/ne_110m_countries.geojson`**(국가 경계)을 기본 탑재합니다. 지구본·머케이터 양쪽이 같은 데이터를 써 줌 인/아웃 시 끊김이 없습니다.
- **부드러운 줌**: 휠 한 번이 즉시 점프하지 않고 `smoothZoomTo()`가 목표 scale을 지수 보간(τ ≈ 90 ms)으로 따라갑니다. 머케이터는 `zoomAtScreen`(커서 아래 지점 유지), 지구본은 `globePickLonLatFromScreen` + `zoomGlobeAtScreen`으로 커서 기준 줌합니다.
- 구체 뷰에서 보이는 것: 별이 박힌 심우주 배경 + 대기 글로우, 세계 대륙(LANDA 톤), 15° 위·경도 그리드, 로드된 ENC 셀 경계(가시=노랑, 비가시=옅은 흰색), 중심 크로스헤어.
- **원근(perspective) 투영**: 카메라 거리 `D = 1 + f / scale`로, 줌이 들어올수록 표면에 접근(평탄)해 머케이터와 거의 일치 → 전환에서 시각적 점프가 없습니다(`projPerspective`, `globeCameraDistance`, `globeFocalLength`).
- **하이브리드에서의 표시 전환**: `tile-mercator.js`가 매 프레임 `vp.isGlobeView()`/`_modeTransition`을 보고, **지구본이면 `#olmap`을 숨겨** 벡터 지구본을, **평면·전환이면 `#olmap`을 보여** 서버 타일을 표시합니다.

### 5.2 뷰포트 즐겨찾기

- 키보드 `Ctrl+1`~`Ctrl+9`로 현재 화면 중심·축척을 슬롯에 저장.
- `1`~`9`로 저장된 슬롯의 뷰포트로 즉시 이동.
- `localStorage` 키 `encViewerBookmarks`에 영속화되어 새로고침해도 유지됩니다.

### 5.3 기타 UI·동작 요약

- **하단 `프로그램 설명`**: `about.html`이 이 문서(`docs/코드-설명.md`)를 불러 렌더합니다.

## 6. 한계·주의사항

- **완전한 ECDIS S-52 구현은 아닙니다.** 조건부 기호·룩업·패턴·복합선 등은 근사·부분 구현입니다. 항해 의사결정에는 공식 ECDIS를 사용하세요.
- **타일 모드**: 서버에 **`canvas`(node-canvas)** 와 충분한 **CPU·메모리**가 필요합니다. 첫 요청·캐시 미스 시 지연이 클 수 있고, `tiles/` 디스크 사용량이 커질 수 있습니다. **스타일 변경 시** `STYLE_VERSION` 상향 + 캐시 비우기/재예열을 잊지 마세요(안 그러면 옛 타일과 새 타일이 섞여 보일 수 있음).
- **객체 단위 토글**은 타일 평면 그림에는 즉시 반영되지 않습니다(서버가 `000/` 전체로 굽습니다). 객체별로 확인하려면 벡터 폴백/지구본에서 보세요.
- S-57 **업데이트 셀(.001 등)** 은 UI에서 accept 되지만, 파이프라인은 **기본 셀(.000)** 중심으로 검증된 경우가 많습니다.
- 좌표계는 웹 머케이터 스타일 투영이며, 공식 해도 표시와 동일한 오차·왜곡 특성을 가집니다.
- 다중 축척 셀 dedup은 휴리스틱(셀 CSCL × 1.5, 24 px 거리)이라, 매우 가까운 정상 인접 항행보조시설이 한 점으로 합쳐질 수 있습니다. 정확한 식별이 필요하면 콘솔에서 `state.renderer.declutter = false`로 끄고 확인하세요.
